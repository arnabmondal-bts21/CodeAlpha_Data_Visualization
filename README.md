# CodeAlpha Data Visualization Project

## Project Title

Data Visualization using Sample Superstore Dataset

## Internship

CodeAlpha Data Analytics Internship

## Task

Task 3: Data Visualization

## Project Overview

This project focuses on transforming raw sales data into meaningful and interactive visual representations. The Sample Superstore dataset was analyzed to understand sales and profit patterns across different categories, regions, and sub-categories.

## Dataset

**Dataset Name:** Sample Superstore Dataset

The dataset contains information about sales, profit, categories, sub-categories, and regions.

## Tools and Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Visualizations Created

1. Total Sales by Category
2. Total Profit by Category
3. Total Sales by Region
4. Total Profit by Region
5. Total Sales by Sub-Category
6. Sales vs Profit
7. Sales Distribution

## Key Insights

* Different product categories contribute differently to total sales and profit.
* Sales and profit vary across regions.
* Some sub-categories generate higher sales than others.
* Higher sales do not always guarantee higher profit.
* Sales data contains variations that can be clearly understood using visual analysis.

## Conclusion

Data visualization helps transform raw data into meaningful insights. This project uses charts and graphs to analyze the Sample Superstore dataset and identify important sales and profit patterns.
